# Project Planning

## Project Objectives

The objective of this project was to design, implement and document a Linux-based network infrastructure for the fictional software development company cqunix.

The project includes:

- Router and firewall implementation
- DHCP services
- Apache web server
- DokuWiki documentation
- SSH server
- Git server
- Backup server
- Security controls
- Documentation and testing
